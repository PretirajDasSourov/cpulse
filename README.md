# CPulse — Production Competitive Programming Platform

CPulse unifies developer activity across **Codeforces**, **VJudge**, **Toph**, **AtCoder**, **CodeChef**, and **LeetCode**.

## 🚀 How to Run Locally

1. Install dependencies:
```bash
npm install
```

2. Copy environment file:
```bash
cp .env.example .env
```

3. Run the development server:
```bash
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000).\n
